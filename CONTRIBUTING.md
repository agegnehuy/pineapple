# Contributing

1. Read [the Git strategy](docs/GIT_STRATEGY.md).
2. Create a short-lived branch from current `main`.
3. Make the smallest complete change and add tests.
4. Run formatting, analysis, tests, and an appropriate device build.
5. Open a pull request using the checklist.

Do not commit `.dart-defines.json`, signing files, API keys, passwords, or generated build output.
