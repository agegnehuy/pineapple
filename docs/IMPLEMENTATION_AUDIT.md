- Saved opportunity metadata has an encrypted, bounded cache isolated by authenticated account and backend. Transport failure can show a timestamped read-only copy; authorization/schema failures cannot. Access denial invalidates cached views/actions across the shared Applications and Saved routes, and an older live response cannot restore permission. A fresh successful request can recover access. Partial copies are labelled, stale mutations are disabled, and successful retry returns to live data. Explicit sign-out deactivates the cache immediately and serializes deletion after earlier writes. Cookies, profile details and document bytes are not cached.
- Shared loading/empty/error/retry behavior, retained forms after failure, duplicate-write guards, destructive-action confirmation, bounded HTTP waits, read-only network retries, safe URL handling, file-size validation, and binary-safe authenticated multipart uploads.

- Profile interests/types use canonical multiselect choices. Retained required fields are validated even after scrolling offscreen. Confirmed profile edits refresh the drawer identity. Session cookie writes are serialized and responses from before sign-out cannot restore the cleared session.
- Requests paused before encrypted-cookie reads are also cancelled if sign-out changes the session boundary. A regression test reproduced an old profile mutation borrowing replacement-session cookies before the fix; it now verifies that no mutation is sent and the replacement session remains usable.
- Multi-request bookmark/authentication operations check the same session generation between requests. Concurrent restoration/sign-out calls are deduplicated, overlapping authentication is rejected, stale controller completions are ignored, and busy authentication forms block Back. Delayed reads cannot continue by writing under a replacement account.
- Small-screen/200% text checks for key new layouts, reduced-motion busy indicators, and Android/iOS page-transition bypass. The coach composer scrolls independently and reveals new responses without animation when reduced motion is requested.
- Long feed-provided locations wrap in variable-height filter choices. Filter, application-status and coach-history sheets honor reduced motion. The coach composer retains an accessible name after text is entered; focused landscape/keyboard and 200% text checks cover these controls.
